## Post-review re-run (2026-09-24)

The runs above predate the merge of `main` into this branch. After that merge
`e2e/a11y.spec.ts` no longer has an `E2E_AUTH` switch or an `/auth/signin`
page: it always mocks an authenticated FLAME user for the app pages. The
numbers above are kept as the historical baseline; this section is the
current state.

- Command: `npm run test:e2e -- e2e/a11y.spec.ts` (mocked REST, Chromium)
- Themes: **dark and light**. Each page is audited once per theme, with the
  theme seeded in `localStorage` the way `public/theme-boot.js` reads it.
- Pages: `/`, `/dashboard`, `/history`, `/analytics`, `/community`, `/cycles`,
  `/routines`, `/profile`, `/recovery`, `/goals`, `/compare`, `/leaderboard`,
  `/challenges`, `/integrations`, `/pricing`
- Gate: unchanged (serious and critical only, WCAG 2.0/2.1 A and AA tags)
- Result: **30 passed, 0 failed** (15 pages × 2 themes)

The first light-mode pass failed on every authenticated page, and adding the
last four pages turned up more failures. All are fixed in this PR:

| Finding | Theme | Fix |
|---|---|---|
| Active sidebar item `#c2410c` on its 12% tint: 4.34:1 | light | `--sidebar-accent-foreground` → `#9a3412` (6.1:1) |
| `text-amber-400` / `text-emerald-400` status text on light surfaces: 1.5–1.8:1 | light | palette classes → `warning` / `success` tokens |
| Warning text on a 20% warning tint: 3.81:1 | light | light `--warning` → `#92400e` |
| `chart-5` purple used as text on its tint: 3.81–4.43:1 | dark | dark `--chart-5` → `#9575ff` |
| Inferno "Upgrade" button: black on `#a16207`, 4.26:1 | light | `text-accent-foreground` |

Companion specs (same run):
- `e2e/a11y-keyboard.spec.ts`: every sidebar link is reached by Tab and shows
  `:focus-visible`, and Ctrl/Cmd+B collapses and expands the sidebar without
  unmounting the app.
- `e2e/a11y-reduced-motion.spec.ts`: all durations are ≤ 1ms and nothing moves
  under `reduce`, with a control run showing the probe detects motion otherwise.
- `e2e/mobile-tap-targets.spec.ts`: every visible control on `/dashboard`,
  `/history` and `/routines` is at least 44×44px on an iPhone 13 viewport.
