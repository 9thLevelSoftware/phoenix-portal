Key Design Decisions

  • Radar chart — ECharts radar with current vs previous period overlay. Instantly shows imbalances. Warning icon on undertrained groups
  • Body heatmap — Enhanced existing SVG silhouette with volume-driven color intensity. Front/Back toggle. Click a region to filter the table below
  • Detailed table — volume, sets, sessions, % of total with inline bar, period delta, and balance status badge per group
  • Biomechanics teaser — blurred preview of Inferno-tier metrics with upgrade CTA. Shows enough to be enticing without giving it away
