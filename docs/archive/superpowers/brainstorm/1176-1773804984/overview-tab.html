Key Design Decisions

  • 5 stat cards with sparklines — every number has trend context (vs period comparison + inline chart)
  • Training Load gauge — ECharts gauge chart, the hero differentiator. RTL score based on volume × intensity × frequency
  • Consistency calendar heatmap — ECharts calendar component, opacity = workout intensity
  • Insights feed — 3-4 contextual cards generated by the rule engine, color-coded by type (success/warning/info/achievement)
  • Volume chart gets session count overlay — dual-axis area + bar combo chart via ECharts
