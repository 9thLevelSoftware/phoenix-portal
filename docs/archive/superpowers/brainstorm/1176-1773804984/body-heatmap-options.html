Body Heatmap — Upgrade Options

Replace the basic silhouette with something that actually looks like anatomy

A

react-muscle-highlighter

MIT License · TypeScript · Actively maintained

Purpose-built React component with detailed anatomical SVG muscle groups — not rectangles, actual muscle shapes (pectorals, deltoids, quadriceps, etc.). Features:

  • Clickable muscle regions — click a muscle to see its stats
  • Intensity levels — set color intensity per muscle group based on volume
  • Front & Back views with toggle
  • Male & female body types
  • Custom color support — we can use the Phoenix ember/flame palette
  • Accessibility & responsive

Pros

  • Drop-in React component, minimal integration work
  • Anatomically detailed muscle outlines
  • Built-in interaction (click, hover)
  • TypeScript types included

Cons

  • Newer library, smaller community
  • Styling locked to their SVG paths (customization has limits)
B

react-body-highlighter

MIT License · More established · 200+ GitHub stars

The original React body highlighter. Polygon-based SVG body with per-muscle highlighting. More battle-tested than react-muscle-highlighter.

  • Exercise-to-muscle mapping — pass exercise names, it highlights the right muscles
  • Intensity levels 0-3 — maps to color opacity
  • Front & Back views
  • onClick handlers per muscle group
  • CSS class customization

Pros

  • More established, used in production apps
  • Exercise-to-muscle auto-mapping is convenient
  • Minimal dependencies

Cons

  • SVG is less anatomically detailed than option A
  • Only 3 intensity levels (coarse granularity)
  • Less active maintenance recently
C

Custom Phoenix SVG (hand-crafted)

$0 · Full control · Most on-brand

Commission or craft a custom SVG body illustration designed specifically for Phoenix Portal's dark theme and ember aesthetic. Think stylized anatomy with a forge/flame visual language — not clinical, not generic.

  • Ember glow effect — muscles glow brighter with more volume, like heated metal
  • Phoenix-branded — unique look no other fitness app has
  • Unlimited muscle granularity — as many regions as the data supports
  • Animated heat transitions — muscles pulse or glow with CSS animations

Pros

  • 100% unique — this becomes a signature visual
  • Perfect integration with the dark theme
  • Full control over granularity and interactions
  • Can animate with existing Framer Motion setup

Cons

  • Most effort to build/commission
  • Need to create or source the base SVG artwork
  • Maintenance burden is on you

My Recommendation: A, with C as a future upgrade

Start with react-muscle-highlighter — it gives you anatomically detailed, interactive muscle visualization with minimal effort. Theme it with the Phoenix palette. Later, if the body map becomes a signature feature worth investing in, commission a custom SVG with the ember glow aesthetic. You already have MuscleHeatmap.tsx in the codebase — the existing SVG can serve as a starting reference for a future custom version.
