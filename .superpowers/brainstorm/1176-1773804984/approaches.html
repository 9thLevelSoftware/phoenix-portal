Analytics Enhancement — Three Approaches

Pick the approach that best matches your vision. All are under $50/mo.

A

ECharts Overhaul + Custom Insights Engine

Cost: $0/mo — All open-source

Charting

Replace Recharts → Apache ECharts. GPU-accelerated Canvas rendering, built-in dark theme, drill-down interactions, animated transitions, 100K+ datapoint performance. Keep visx for telemetry force curves.

Insights

Build a rule-based training intelligence engine in Supabase Edge Functions. Resistance Training Load (RTL) scoring, plateau detection, muscle balance alerts, streak/consistency scoring, recovery estimation. No AI API costs.

Social

Community percentile rankings via aggregate Supabase queries. "Top 20% for weekly volume", exercise-specific leaderboards.

Pros

  • Zero ongoing costs
  • ECharts is massively capable (maps, gauges, radar, heatmaps)
  • Rule-based insights are deterministic and predictable
  • Huge community & documentation

Cons

  • Larger migration effort (replace all Recharts code)
  • ECharts API is option-object based, less "React-native"
  • Rule-based insights lack the natural language feel of AI
  • Bundle size ~800KB (tree-shakeable)
B

Nivo Upgrade + LLM Coaching Layer

Cost: $20-40/mo — Claude API for insights

Charting

Replace Recharts → Nivo. Built on D3, React-native components, excellent theming, SVG/Canvas/HTML rendering. Beautiful defaults, great animations. Keep visx for force curves.

Insights

Use Claude API via Edge Function to generate personalized coaching. "Your bench press has stalled for 3 weeks — try paused reps or drop the weight 10% and add volume." Natural language, contextual, specific.

Social

Same percentile rankings, plus AI-powered peer comparisons.

Pros

  • Most React-idiomatic charting API
  • AI coaching feels premium and personal
  • Natural language insights are more engaging
  • Nivo's theming system is excellent

Cons

  • $20-40/mo API costs (scales with users)
  • AI can hallucinate bad training advice
  • Nivo has fewer chart types than ECharts
  • API latency adds loading time to insights
C

Maximize Existing Stack + Content Focus

Cost: $0/mo — No library changes

Charting

Keep Recharts + visx as-is. Instead of replacing them, add new chart types and enhance existing ones with better tooltips, comparison overlays, sparklines, trend indicators.

Insights

Build same rule-based engine as Approach A. Focus effort on data enrichment — better muscle group categorization, derived metrics (estimated 1RM, volume load, training density), period comparisons.

Social

Community percentile rankings. Same approach, less polish.

Pros

  • Fastest to ship — no migration
  • Zero risk of breaking existing charts
  • Zero costs
  • Can iterate quickly on content

Cons

  • Recharts still looks generic
  • Limited chart types (no radar, gauge, heatmap calendar)
  • Harder to differentiate from free fitness apps
  • visx has a steep learning curve for new chart types

My Recommendation: Approach A

Apache ECharts gives you the most visual differentiation at zero cost. Its built-in gauge charts, radar plots, calendar heatmaps, and animated transitions will make the analytics page feel like a premium product. The rule-based insights engine avoids AI cost scaling and hallucination risk while still delivering the "dashboard that talks to you" experience. You can always add an LLM layer later as a premium Inferno-tier feature.
