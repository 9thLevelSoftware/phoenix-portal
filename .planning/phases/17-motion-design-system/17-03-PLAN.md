src/app/components/LandingPage.tsx
  </files>
  <action>
Add scroll-driven parallax to the landing page hero section using Framer Motion's `useScroll` and `useTransform`.

**Implementation:**

1. Import `useScroll`, `useTransform`, `motion` from `motion/react`
2. At the top of the LandingPage component (or the hero section component), add:
```tsx
const { scrollY } = useScroll();
const heroY = useTransform(scrollY, [0, 500], [0, -80]);
const heroOpacity = useTransform(scrollY, [0, 400], [1, 0]);
```

3. Wrap the hero content container (the text + CTA block, NOT the background/gradient) in a `motion.div` with:
```tsx
<motion.div style={{ y: heroY, opacity: heroOpacity }}>
  {/* existing hero content: h1, subtitle, CTA buttons */}
</motion.div>
```

**Key details:**
- Only the text/CTA content moves — background stays fixed (natural parallax depth)
- Y range [0, -80] is subtle — hero content drifts up as user scrolls, creating depth
- Opacity fade [1, 0] over 400px prevents stale content lingering at scroll bottom
- `useScroll` is passive (no layout thrashing) — uses `onScroll` event internally
- Do NOT apply parallax to the EmberParticles canvas — it already has its own scroll behavior
- Reduced motion: MotionConfig handles this automatically (style transforms are reduced)
  </action>

3. `npm run typecheck` — should pass
  </verify>

  <action>
Find the scroll indicator element on the landing page (typically a down-arrow or chevron near the bottom of the hero section that uses Tailwind's `animate-bounce` class).

**Replace** the Tailwind `animate-bounce` with a Framer Motion breathing animation using the preset from `animations.ts`:

1. Import `breathing` from `@/lib/animations`
2. Find the scroll indicator element (likely has `animate-bounce` class)
3. Convert it to a `motion.div` (or wrap it) and apply:
```tsx
<motion.div animate={breathing.animate}>
  {/* existing scroll indicator icon/chevron */}
</motion.div>
```
4. Remove the `animate-bounce` class from the element

**Why breathing over bounce:**
- `animate-bounce` uses a cubic-bezier that feels mechanical (CSS timing function)
- The breathing preset uses easeInOut with a 2s cycle — feels organic, like a gentle pulse
- Includes opacity variation (0.6 → 1 → 0.6) for a softer, more premium feel

**If no scroll indicator exists:** Check for any element with `animate-bounce` in LandingPage. If truly absent, create a minimal scroll indicator at the bottom of the hero section:
```tsx
<motion.div
  className="absolute bottom-8 left-1/2 -translate-x-1/2"
  animate={breathing.animate}
>
  <ChevronDown className="w-6 h-6 text-muted-foreground" />
</motion.div>
```
