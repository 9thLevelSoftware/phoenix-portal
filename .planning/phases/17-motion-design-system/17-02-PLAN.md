  <action>
Replace the `<Outlet />` component with a `useOutlet()` + `AnimatePresence` pattern for page transitions.

**Why useOutlet():** React Router v7's `<Outlet />` unmounts the previous route immediately on navigation. `useOutlet()` returns a React element reference that AnimatePresence can hold during exit animation.

**Changes to AppLayout.tsx:**

1. Add imports:
```tsx
import { useOutlet, useLocation } from "react-router";
import { AnimatePresence, motion } from "motion/react";
import { pageTransition } from "@/lib/animations";
```

2. Inside the AppLayout function body, add:
```tsx
const outlet = useOutlet();
const location = useLocation();
```

3. Replace the existing:
```tsx
<ErrorBoundary FallbackComponent={PageErrorFallback}>
  <Suspense fallback={<PageLoading />}>
    <Outlet />
  </Suspense>
</ErrorBoundary>
```

With:
```tsx
<ErrorBoundary FallbackComponent={PageErrorFallback}>
  <Suspense fallback={<PageLoading />}>
    <AnimatePresence mode="wait">
      <motion.main
        key={location.pathname}
        id="main-content"
        {...pageTransition}
      >
        {outlet}
      </motion.main>
    </AnimatePresence>
  </Suspense>
</ErrorBoundary>
```

**Key details:**
- `mode="wait"` ensures exit completes before enter starts (no overlapping routes)
- `key={location.pathname}` triggers AnimatePresence to detect route changes
- `id="main-content"` preserves the skip-to-content target (check if SkipToContent references this ID)
- The `<motion.main>` uses `pageTransition` from animations.ts (initial/animate/exit)
- Remove the `Outlet` import if no longer used elsewhere in this file

**CAUTION:**
- Do NOT move MotionConfig, SidebarProvider, ErrorBoundary, or Suspense — only the Outlet replacement
- Keep the existing `data-print-hide` wrappers for AppSidebar and MobileBottomNav unchanged
- The Suspense fallback still renders PageLoading during lazy chunk loading — AnimatePresence only handles transition between loaded pages

Replace the generic CSS spinner in PageLoading with a branded Phoenix flame animation.

**Current state:** Simple `border-2 border-primary border-t-transparent rounded-full animate-spin` CSS spinner.

**New implementation:** Use a Framer Motion animated SVG flame icon with a pulsing glow effect that matches the Phoenix brand.

```tsx
import { motion } from "motion/react";
import { Flame } from "lucide-react";

export function PageLoading() {
  return (
    <div className="flex-1 flex items-center justify-center h-[calc(100vh-4rem)]">
      <div className="flex flex-col items-center gap-4">
        <motion.div
          animate={{
            scale: [1, 1.15, 1],
            opacity: [0.7, 1, 0.7],
          }}
          transition={{
            duration: 1.5,
            repeat: Infinity,
            ease: "easeInOut",
          }}
          className="relative"
        >
          <Flame className="w-10 h-10 text-primary" strokeWidth={1.5} />
          <motion.div
            className="absolute inset-0 rounded-full bg-primary/20 blur-xl"
            animate={{
              scale: [0.8, 1.3, 0.8],
              opacity: [0.3, 0.6, 0.3],
            }}
            transition={{
              duration: 1.5,
              repeat: Infinity,
              ease: "easeInOut",
            }}
          />
        </motion.div>
        <p className="text-muted-foreground text-sm">Loading...</p>
      </div>
    </div>
  );
}
```

**Key details:**
- Uses Lucide `Flame` icon (already in the project's icon set)
- Pulsing scale + opacity creates a "breathing flame" effect
- Background blur glow radiates the ember color behind the icon
- Reduced motion: MotionConfig at AppLayout level will suppress these animations automatically
- No new dependencies — uses existing motion + lucide-react
