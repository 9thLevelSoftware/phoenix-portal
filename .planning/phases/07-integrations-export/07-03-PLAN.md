Create src/lib/integrations/hevy.ts:

Export parseHevyCSV(csvContent: string): NormalizedActivity[]:
- Parse CSV using react-papaparse readString
- CSV columns per research: title, start_time, end_time, description, exercise_title, superset_id, exercise_notes, set_index, set_type, weight_lbs, reps, distance_miles, duration_seconds, rpe
- Group rows by workout (title + start_time combination)
- For each workout group:
  - external_id: `hevy-${title}-${start_time_timestamp}`
  - provider: 'hevy'
  - name: title
  - activity_type: 'strength'
  - started_at: ISO string of start_time
  - duration_seconds: end_time - start_time in seconds
  - calories: null (Hevy doesn't export calories)
  - Other metrics null (Hevy is strength-focused)
- Return array of NormalizedActivity

Export normalizeHevyActivity(raw: unknown): NormalizedActivity:
- For API responses (structure TBD)
- Include Zod schema for validation

Install dependency: npm install react-papaparse
