  <action>
Create Edge Function that handles Strava OAuth callback per research pattern.

The function:
1. Receives code and state (user_id) from Strava redirect
2. Exchanges code for access_token and refresh_token via POST to https://www.strava.com/oauth/token
3. Extracts athlete.id from response as provider_user_id
4. Upserts to user_integrations table with:
   - user_id from state
   - provider: 'strava'
   - provider_user_id: String(tokens.athlete.id)
   - access_token, refresh_token
   - token_expires_at: new Date(tokens.expires_at * 1000).toISOString()
   - status: 'connected'
5. Queues initial sync by inserting to sync_queue
6. Redirects to ${APP_URL}/integrations?connected=strava

Environment variables needed:
- STRAVA_CLIENT_ID
- STRAVA_CLIENT_SECRET
- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY
- APP_URL (portal URL for redirect)

Use createClient with service role key (not anon key) since this is server-side operation without user JWT.

Handle errors:
- Missing code/state: Redirect to /integrations?error=missing_params
- Token exchange failure: Redirect to /integrations?error=auth_failed
- Database error: Redirect to /integrations?error=save_failed

Create supabase/functions/strava-sync/index.ts:
- Receives { user_id, sync_type } in request body
- Fetches user's Strava tokens from user_integrations
- Checks token expiry, refreshes if needed (POST to /oauth/token with refresh_token)
- Fetches activities from https://www.strava.com/api/v3/athlete/activities
  - For initial sync: page=1, per_page=200 (last 200 activities)
  - For incremental: after=last_sync_timestamp
- Normalizes each activity using normalizeStravaActivity
- Upserts to external_activities (on conflict: user_id, provider, external_id)
- Updates last_sync_at in user_integrations
- Returns { synced_count, errors }

Create src/lib/integrations/strava.ts:
- Export initiateStravaConnect(userId: string): void
  - Builds OAuth URL with client_id, redirect_uri (Edge Function URL), response_type=code, scope=activity:read_all, state=userId
  - Sets window.location.href to redirect user
- Export normalizeStravaActivity(activity: StravaActivity): NormalizedActivity
  - Maps fields per research (elapsed_time -> duration_seconds, etc.)
  - Converts kilojoules to calories (kj * 0.239)
  - Maps sport_type to activity_type
- Export StravaActivity Zod schema for raw API response validation

Create src/app/components/integrations/StravaConnect.tsx:
- Simple component with Connect button
- On click, calls initiateStravaConnect(userId)
- Shows loading state during redirect
- Uses VITE_STRAVA_CLIENT_ID for OAuth URL construction

Add VITE_STRAVA_CLIENT_ID to .env.example (public, safe for client).
