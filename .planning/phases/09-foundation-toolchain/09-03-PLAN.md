For each of the 15 files listed:
1. Search for `dark:` class prefixes
2. For each `dark:` variant found, determine the intended style:
   - If the `dark:` style is the one we WANT (since we're always dark), move it to the base style and remove the `dark:` prefix
   - If the base (light) style is what's already correct for our dark theme, just remove the `dark:` variant entirely
   - Example: `"bg-white dark:bg-gray-900"` → since we're dark-only, this becomes `"bg-gray-900"` (or better: `"bg-surface-0"` if the surface token applies)

**Common patterns to look for:**
- `dark:bg-*` → use the dark value as the base value
- `dark:text-*` → use the dark value as the base value
- `dark:border-*` → use the dark value as the base value
- `dark:ring-*` → use the dark value as the base value
- `dark:hover:*` → use the dark hover value as base hover

Where possible, replace hardcoded colors with semantic tokens (bg-background, text-foreground, bg-surface-1, etc.).
