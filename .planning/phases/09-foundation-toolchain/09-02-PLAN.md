<task type="auto">
  <name>Task 1: Install Biome 2.4, create config, enable TypeScript strictness, add visualizer</name>
  <files>package.json, biome.json, tsconfig.app.json, vite.config.ts</files>
  <action>
**Biome installation:**
Run: `npm install -D @biomejs/biome@^2.4.0`

Create `biome.json` with this configuration:
```json
{
  "$schema": "https://biomejs.dev/schemas/2.4.0/schema.json",
  "vcs": {
    "enabled": true,
    "clientKind": "git",
    "useIgnoreFile": true
  },
  "files": {
    "ignoreUnknown": false,
    "includes": ["src/**/*.ts", "src/**/*.tsx", "vite.config.ts"]
  },
  "formatter": {
    "enabled": true,
    "indentStyle": "tab",
    "lineWidth": 80
  },
  "linter": {
    "enabled": true,
    "rules": {
      "recommended": true
    }
  },
  "javascript": {
    "formatter": {
      "quoteStyle": "double",
      "semicolons": "always"
    }
  },
  "assist": {
    "enabled": true,
    "actions": {
      "source": {
        "organizeImports": "on"
      }
    }
  }
}
```

Run `npx @biomejs/biome check ./src` to see the current state. Expect formatting violations (not lint errors, since code is functional). If there are lint errors that are NOT pre-existing bugs, suppress them with `// biome-ignore` comments and a reason. If they ARE pre-existing bugs, fix them.

**TypeScript strictness:**
In `tsconfig.app.json`, set:
- `"noUnusedLocals": true`
- `"noUnusedParameters": true`

Research confirms ZERO violations exist — this should be a clean enable.

Run `npm run build` to verify zero TS errors with new settings.

**Bundle visualizer:**
Run: `npm install -D rollup-plugin-visualizer`

In `vite.config.ts`, add conditional visualizer plugin:
```typescript
import { visualizer } from 'rollup-plugin-visualizer';

// Inside plugins array, add:
...(process.env.ANALYZE === 'true'
  ? [visualizer({ open: true, gzipSize: true, brotliSize: true })]
  : []),
```

Add `"analyze": "ANALYZE=true vite build"` script to package.json.

Commit ONLY the config files (biome.json, tsconfig.app.json, vite.config.ts, package.json):
```
chore(09-02): add Biome 2.4 config, enable TS strict unused checks, wire bundle visualizer
```

**Format the entire codebase:**
Run: `npx @biomejs/biome format --write ./src`
Run: `npx @biomejs/biome format --write ./vite.config.ts`

This will reformat all source files to Biome's style (tabs, double quotes, semicolons, 80-char line width). This is a large change — every file in src/ will be touched.

**Commit the formatting changes:**
Stage ALL changed files and commit with:

Create `.git-blame-ignore-revs` (or append to it if it exists):

Use `git rev-parse HEAD` to get the hash after the formatting commit.

Commit `.git-blame-ignore-revs`:

chore(09-02): add formatting commit to .git-blame-ignore-revs

**Configure git locally:**
Run: `git config blame.ignoreRevsFile .git-blame-ignore-revs`

**Final lint check:**
