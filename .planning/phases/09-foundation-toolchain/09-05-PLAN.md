  <files>src/app/components/*.tsx, src/app/components/mobile/*.tsx, src/app/components/routine-builder/*.tsx, src/app/components/cycle-builder/*.tsx, src/app/components/celebrations/*.tsx</files>
  <action>
**Scope:** Replace Tailwind arbitrary value hex colors with semantic token classes across ALL feature component files (NOT ui/ components — those were cleaned in Plan 09-03).

**Migration patterns (search → replace):**

Primary/Ember (#FF6B35):
- `text-[#FF6B35]` → `text-primary`
- `bg-[#FF6B35]` → `bg-primary`
- `border-[#FF6B35]` → `border-primary`
- `from-[#FF6B35]` → `from-primary`
- `to-[#FF6B35]` → `to-primary` (or `to-accent` depending on gradient context)
- `ring-[#FF6B35]` → `ring-primary`
- `hover:text-[#FF6B35]` → `hover:text-primary`
- `hover:bg-[#FF6B35]` → `hover:bg-primary`

Flame Red (#DC2626):
- `text-[#DC2626]` → `text-destructive` (if error context) or `text-chart-2` (if chart context)
- `bg-[#DC2626]` → `bg-destructive`
- `border-[#DC2626]` → `border-destructive`

Gold (#F59E0B):
- `text-[#F59E0B]` → `text-accent`
- `bg-[#F59E0B]` → `bg-accent`
- `border-[#F59E0B]` → `border-accent`

Forge Green (#10B981):
- `text-[#10B981]` → `text-success`
- `bg-[#10B981]` → `bg-success`

Crimson (#EF4444):
- `text-[#EF4444]` → `text-destructive`
- `bg-[#EF4444]` → `bg-destructive`

Flame Yellow (#FBBF24):
- `text-[#FBBF24]` → `text-warning`
- `bg-[#FBBF24]` → `bg-warning`

Background (#0D0D0D):
- `bg-[#0D0D0D]` → `bg-background` or `bg-surface-0`
- `text-[#0D0D0D]` → `text-background`

White (#FFFFFF):
- `text-[#FFFFFF]` → `text-foreground`
- `bg-[#FFFFFF]` → `bg-foreground` (rare, usually for contrast elements)
- Note: `text-white` (non-arbitrary) is fine — leave as-is

Gray shades:
- `text-[#6B7280]` → `text-muted`
- `text-[#9CA3AF]` → `text-muted-foreground`
- `bg-[#374151]` → `bg-secondary`
- `text-[#E5E7EB]` → `text-secondary-foreground`

**Execution strategy:**
1. Use grep to find all files with hardcoded hex in Tailwind arbitrary syntax
2. Work through files systematically, reading each file and applying replacements
3. Use context to determine semantic mapping (e.g., red in error context = destructive, red in chart = chart-2)
4. For hex values with opacity modifiers (e.g., `bg-[#FF6B35]/10`), use `bg-primary/10`
5. For rgba() in inline styles, convert to `var(--phoenix-ember)` or `var(--primary)` as appropriate

**DO NOT convert:**
- Colors inside `style={{ }}` JSX — these will be handled as inline style migrations if needed
- Colors in SVG stroke/fill attributes — handled in Task 2
- Colors in motion.div animate targets — handled in Task 2
- Colors in `src/app/components/ui/` — already cleaned in Plan 09-03

Run `npm run build` after completing each batch of ~10 files to catch errors early.

  <files>src/app/components/*.tsx, src/app/components/mobile/*.tsx, src/app/components/routine-builder/*.tsx, src/app/components/cycle-builder/*.tsx, src/app/components/celebrations/*.tsx</files>
  <action>
**SVG stroke/fill migration:**
Find all SVG elements with hardcoded hex colors in stroke or fill attributes:
- `stroke="#FF6B35"` → `stroke={PHOENIX.ember}`
- `fill="#FF6B35"` → `fill={PHOENIX.ember}`
- `stroke="#DC2626"` → `stroke={PHOENIX.flameRed}`
- `fill="#DC2626"` → `fill={PHOENIX.flameRed}`
- `stroke="#F59E0B"` → `stroke={PHOENIX.gold}`
- `fill="#10B981"` → `fill={PHOENIX.forgeGreen}`
- `stroke="#EF4444"` → `stroke={PHOENIX.crimson}`
- `fill="#0D0D0D"` → `fill={PHOENIX.black}`
- `stroke="#6B7280"` → `stroke={PHOENIX.ashGray}`
- `fill="#374151"` → `fill={PHOENIX.moltenSteel}`
- (and similar for other Phoenix palette colors)

Each file that uses PHOENIX constants needs: `import { PHOENIX } from "@/lib/colors";`

**Framer Motion animate migration:**
Find motion.div/motion.span etc. with hardcoded hex in animate targets:
- `animate={{ color: "#FF6B35" }}` → `animate={{ color: PHOENIX.ember }}`
- `animate={{ backgroundColor: "#0D0D0D" }}` → `animate={{ backgroundColor: PHOENIX.black }}`
- `initial={{ color: "#6B7280" }}` → `initial={{ color: PHOENIX.ashGray }}`
- Similar for `opacity` targets that include color values
- Check `variants` objects for hardcoded hex

Also check:
- `style={{ color: "#FF6B35" }}` → `style={{ color: "var(--phoenix-ember)" }}` (inline styles CAN use CSS vars)
- `style={{ backgroundColor: "#0D0D0D" }}` → `style={{ backgroundColor: "var(--background)" }}`
- But ONLY convert to CSS vars for static inline styles, not for motion animate targets

**Execution strategy:**
1. Grep for SVG hex patterns: `grep -rn 'stroke="#\|fill="#' src/app/components/ --include="*.tsx" | grep -v "/ui/"`
2. Grep for motion hex patterns: `grep -rn 'animate.*#[0-9A-Fa-f]' src/app/components/ --include="*.tsx"`
3. Grep for inline style hex: `grep -rn 'style=.*#[0-9A-Fa-f]' src/app/components/ --include="*.tsx" | grep -v "/ui/"`
4. Add `import { PHOENIX } from "@/lib/colors"` to each file that needs it
5. Replace hex strings with PHOENIX constant references

**Important:** If a file already has some imports from `@/lib/colors`, merge the import. Don't create duplicate import lines.

Run `npm run build` after each batch to verify.
