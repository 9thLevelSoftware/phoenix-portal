  <name>Task 1: Generate real analytics insights from query data</name>
  <files>src/app/components/Analytics.tsx</files>
  <action>
Replace the TODO insights block (lines 168-190) with a `generateInsights` function that derives insights from the already-available data variables: `volumeData`, `muscleGroupData`, `strengthExercises`, `totalWorkouts`, `totalVolume`.

The function should produce an array of `{ type: 'positive' | 'warning' | 'neutral', title: string, description: string, icon: ComponentType }` objects.

**Required insight categories (implement all 4 + fallback):**

1. **Volume Trend** (requires `volumeData.length >= 2`):
   - Compare last two entries: `volumeData[length-1].volume` vs `volumeData[length-2].volume`
   - If increase > 0%: positive, "Volume Trending Up", "{change}% increase vs previous week", TrendingUp icon
   - If decrease > 20%: warning, "Volume Drop Detected", "{change}% decrease -- consider if this is an intentional deload or missed sessions", TrendingDown icon
   - If decrease 0-20%: neutral, "Volume Stable", "Slight {change}% decrease -- within normal variation", Activity icon
   - Guard: skip this insight if `volumeData.length < 2`

2. **Muscle Balance** (requires `muscleGroupData.length >= 2`):
   - Sort by `value` descending, compare highest vs lowest
   - If dominant > 3x weakest: warning, "Muscle Imbalance", "{dominant.name} at {dominant.value}% vs {weakest.name} at {weakest.value}% -- consider more {weakest.name} work", AlertCircle icon
   - Else: positive, "Balanced Training", "Good distribution across {N} muscle groups", Target icon
   - Guard: skip if `muscleGroupData.length < 2`

3. **Consistency** (requires `totalWorkouts > 0`):
   - Calculate average workouts per week: `Math.round(totalWorkouts / Math.max(volumeData.length, 1))`
   - If >= 3/week: positive, "Great Consistency", "Averaging {N} workouts per week", Activity icon
   - If 1-2/week: neutral, "Room to Grow", "Averaging {N} workouts per week -- 3+ is ideal for progress", Activity icon
   - Guard: skip if `totalWorkouts === 0`

4. **Strength Tracking** (requires `strengthExercises.length > 0`):
   - positive, "Strength Tracking Active", "Tracking progress on {N} exercises: {first 3 names joined}", TrendingUp icon
   - Guard: skip if `strengthExercises.length === 0`

5. **Fallback** (if all guards skip, array is empty):
   - neutral, "Building Your Profile", "Complete more workouts to unlock personalized training insights", Activity icon

**Implementation pattern:**
- Define `generateInsights` as a standalone function ABOVE the component (not inside it, to avoid recreation on re-renders)
- Call it inside the component: `const insights = generateInsights(volumeData, muscleGroupData, strengthExercises, totalWorkouts);`
- Remove the TODO comment
- Icons are already imported: TrendingUp, TrendingDown, Activity, Target, AlertCircle are all in the existing lucide-react import

**PITFALL:** Every insight description that includes computed values MUST guard against NaN/Infinity. Use `previous > 0` before division, use `Math.max(denominator, 1)` for averages, and use `Math.abs()` for displaying negative changes.
