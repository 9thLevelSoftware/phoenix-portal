  <action>
Create `src/app/components/PageShell.tsx`:

```tsx
import { cn } from "@/lib/utils";

interface PageShellProps {
  children: React.ReactNode;
  className?: string;
}

export function PageShell({ children, className }: PageShellProps) {
  return (
    <div className={cn(
      "max-w-7xl mx-auto px-4 md:px-6 py-6 md:py-8",
      className
    )}>
      {children}
    </div>
  );
}
```

This is a thin wrapper. SidebarInset (from AppLayout's SidebarProvider in Plan 01) already handles the left-margin offset as the sidebar collapses/expands. PageShell ONLY owns internal padding and max-width.

Do NOT apply PageShell to:
- LandingPage (unauthenticated, has its own full-bleed layout)
- Any public/auth routes outside AppLayout
- Inner sub-sections within pages that have their own max-w constraints (e.g., print layouts, sticky headers with different widths)
