**General merge pattern:**
1. Read the mobile variant fully to understand what differs from desktop
2. In the parent component, remove the `if (isMobile) return <XMobile />` branch
3. Remove the `useIsMobile` import if no longer needed in that file
4. Where layouts differ, use responsive Tailwind classes: `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`
5. Where markup is fundamentally different between mobile/desktop, use `block md:hidden` / `hidden md:block` to render both and let CSS choose
6. Migrate any unique data-fetching hooks from the mobile variant that don't exist in the parent (prevent duplicate hook calls)
7. Delete the mobile variant file
