  <name>Task 1: Define card tier CSS utilities and add dialog overlay blur</name>
  <files>src/styles/theme.css, src/app/components/ui/dialog.tsx</files>
  <action>
**In `src/styles/theme.css`**, add a new `@layer utilities` block AFTER the existing `@layer base` block (but BEFORE the print utilities). Define these CSS utility classes:

1. `.card-hero` — for streak, active goal, recovery score cards (max 1 per page):
   ```css
   .card-hero {
     background: linear-gradient(135deg, rgba(255,107,53,0.12) 0%, rgba(220,38,38,0.06) 100%);
     border: 2px solid rgba(255, 107, 53, 0.4);
     box-shadow: var(--shadow-lg), 0 0 20px rgba(255, 107, 53, 0.12);
   }
   ```

2. `.card-primary` — for key metric cards with glassmorphism (max 2 per viewport on desktop, 0 on mobile):
   ```css
   .card-primary {
     background: rgba(26, 26, 26, 0.6);
     border: 1px solid rgba(255, 255, 255, 0.08);
     box-shadow: var(--shadow-md);
   }
   @media (min-width: 768px) {
     .card-primary {
       backdrop-filter: blur(12px);
       -webkit-backdrop-filter: blur(12px);
     }
   }
   ```
   Desktop-only blur prevents exceeding the 3-layer backdrop-blur budget on mobile (MobileBottomNav + sticky header already use 2 layers).

3. `.card-secondary` — for informational content (default tier):
   ```css
   .card-secondary {
     background: linear-gradient(135deg, var(--surface-2), var(--surface-0));
     border: 1px solid rgba(255, 255, 255, 0.06);
     box-shadow: var(--shadow-sm);
   }
   ```

4. `.card-landing-feature` — landing page gradient border cards with hover lift + glow:
   ```css
   .card-landing-feature {
     border: 1px solid transparent;
     background:
       padding-box linear-gradient(135deg, var(--surface-2), var(--surface-0)),
       border-box linear-gradient(135deg,
         rgba(255, 107, 53, 0.5) 0%,
         rgba(220, 38, 38, 0.25) 50%,
         rgba(245, 158, 11, 0.1) 100%);
     box-shadow: var(--shadow-sm);
     transition: transform 200ms ease, box-shadow 200ms ease;
   }
   .card-landing-feature:hover {
     transform: translateY(-3px);
     box-shadow: var(--shadow-lg), 0 0 24px rgba(255, 107, 53, 0.2);
   }
   ```

**In `src/app/components/ui/dialog.tsx`**, find the `DialogOverlay` component and add `backdrop-blur-sm` to its className alongside the existing `bg-black/80` (or `bg-black/50`). This is a baseline improvement for ALL dialogs — a subtle 4px blur on the overlay is standard practice and improves the glass card effect for VIS-07. Do NOT change DialogContent here — the glass treatment is applied per-instance in LandingPage.tsx.

**CRITICAL CONSTRAINTS:**
- Do NOT use `border-image` anywhere (breaks border-radius)
- Do NOT use `will-change: backdrop-filter` on static cards
- Always include `-webkit-backdrop-filter` alongside `backdrop-filter` in raw CSS
- The `@layer utilities` block goes AFTER `@layer base` closing brace, BEFORE the `.print-only` rule
  </action>
