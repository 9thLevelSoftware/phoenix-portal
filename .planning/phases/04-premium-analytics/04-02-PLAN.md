<task type="auto">
  <name>Task 2: Build ForceCurve visx component with gradient fill and multi-rep overlay</name>
  <files>src/app/components/charts/ForceCurve.tsx</files>
  <action>
    Create `src/app/components/charts/ForceCurve.tsx`:

    **Props interface `ForceCurveProps`:**
    - `repData: Array<{ repNumber: number; points: TelemetryPoint[] }>` -- one or more reps to render
    - `width?: number` -- if omitted, use ParentSize for responsive
    - `height?: number` -- default 300
    - `normalized?: boolean` -- default false. When true, uses normalizeRepTime for overlay alignment.
    - `showTooltip?: boolean` -- default true
    - `selectedRep?: number | null` -- highlights one rep, dims others

    **Implementation pattern:**
    1. Wrap component in `ParentSize` from `@visx/responsive` for responsive sizing
    2. For each rep's data, call `downsampleTelemetry(points, 'force', 750)` via `useMemo`
    3. If `normalized`, apply `normalizeRepTime` to each rep's downsampled data
    4. Compute scales:
       - xScale: `scaleLinear` domain = [0, max timestamp_ms] (or [0, 100] if normalized), range = [marginLeft, width - marginRight]
       - yScale: `scaleLinear` domain = [0, max force_n * 1.1 for headroom], range = [height - marginBottom, marginTop]
    5. Render SVG:
       - `<LinearGradient>` def for each rep (using REP_COLORS[index], fading to transparent)
       - For each rep: `<AreaClosed>` with `curveMonotoneX` for gradient fill, then `<LinePath>` for crisp stroke
       - If `selectedRep` is set, apply `opacity={0.2}` to non-selected reps
       - `<AxisBottom>` with label "Time (ms)" or "Time (%)" if normalized
       - `<AxisLeft>` with label "Force (N)"
       - Both axes styled with `CHART_COLORS.axisText` tick color and `CHART_COLORS.gridLine`
    6. Tooltip:
       - Use `useChartTooltip` from shared
       - On mousemove over SVG, find nearest data point using bisector, show tooltip with rep number + force value + timestamp
       - Use `ChartTooltipContent` for rendering
    7. Add `shapeRendering="optimizeSpeed"` on path elements for performance (per research pitfall #1)
    8. Export as named export: `export function ForceCurve(...)`
  </action>
  <verify>
    `npm run build` succeeds. ForceCurve component exports correctly. Verify visx imports resolve: AreaClosed from @visx/shape, LinearGradient from @visx/gradient, scaleLinear from @visx/scale, curveMonotoneX from @visx/curve, ParentSize from @visx/responsive, AxisBottom/AxisLeft from @visx/axis.
  </verify>
