       ```bash
       npm install @visx/shape @visx/scale @visx/gradient @visx/curve @visx/tooltip @visx/responsive @visx/axis @visx/group @visx/grid downsample
       ```
       Do NOT install `@visx/visx` umbrella -- individual packages only.

    2. Create `src/lib/telemetry.ts`:
       - Export `TelemetryPoint` interface with fields: `timestamp_ms: number`, `force_n: number`, `velocity_mps: number`, `position_mm: number`, `cable: 'left' | 'right'`
       - Create two typed LTTB downsamplers using `createLTTB` from `downsample`:
         - `forceLTTB`: x = timestamp_ms, y = force_n
         - `velocityLTTB`: x = timestamp_ms, y = velocity_mps
       - Export `downsampleTelemetry(raw: TelemetryPoint[], metric: 'force' | 'velocity', targetPoints = 750): TelemetryPoint[]`
         - Short-circuit if raw.length <= targetPoints
         - Select appropriate LTTB function by metric
       - Export `normalizeRepTime(points: TelemetryPoint[]): (TelemetryPoint & { normalizedTime: number })[]`
         - Maps timestamp_ms to 0-100 range (percentage of rep duration) for overlay comparisons

    3. Create `src/lib/vbt.ts`:
       - Export `VbtZone` type union: 'absolute-strength' | 'accelerative-strength' | 'strength-speed' | 'speed-strength' | 'starting-strength'
       - Export `VbtZoneInfo` interface with: zone, label, color (Phoenix theme), minVelocity, maxVelocity, description
       - Export `VBT_ZONES` array with Dr. Bryan Mann's thresholds:
         - absolute-strength: 0-0.5 m/s, color #DC2626 (Flame Red)
         - accelerative-strength: 0.5-0.75, color #FF6B35 (Ember)
         - strength-speed: 0.75-1.0, color #F59E0B (Gold)
         - speed-strength: 1.0-1.3, color #10B981 (Forge Green)
         - starting-strength: 1.3+, color #3B82F6 (Blue)
       - Export `classifyVbtZone(meanVelocityMps: number): VbtZoneInfo` -- finds matching zone, fallback to absolute-strength

    4. Create `src/lib/biomechanics.ts`:
       - Export `ASYMMETRY_THRESHOLD = 10` (percent)
       - Export `calculateAsymmetry(leftForce: number, rightForce: number): number` -- returns signed percentage: `((right - left) / total) * 200`. Positive = right dominant.
       - Export `estimateOneRepMax(weight: number, reps: number): number` -- Epley formula: `weight * (1 + reps / 30)`, rounded. Returns 0 for invalid inputs, weight itself for reps=1.
       - Export `calculatePower(forceNewtons: number, velocityMps: number): number` -- returns `Math.round(force * velocity)` in watts.
       - Export `calculateRom(positions: number[]): number` -- returns `Math.round(max - min)` in mm.
  </action>
