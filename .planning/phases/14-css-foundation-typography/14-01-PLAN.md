  <action>
**index.html:**
1. Replace the Google Fonts `<link>` tag. Remove `Bebas+Neue` entirely (no longer used). Change Inter from discrete weights (`wght@400;500;600;700`) to variable font range syntax (`wght@0,100..900;1,100..900`). This unlocks non-standard weights 450 and 625.

Replace:
```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Bebas+Neue&family=Inter:wght@400;500;600;700&display=swap">
```
With:
```html
<link rel="preload" as="style" href="https://fonts.googleapis.com/css2?family=Inter:ital,wght@0,100..900;1,100..900&display=swap">
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:ital,wght@0,100..900;1,100..900&display=swap">
```
Keep the existing preconnect tags unchanged.

**src/styles/fonts.css:**
2. Replace the entire file content with:
```css
/* Phoenix Typography — Inter Variable */

@theme {
  --font-sans: "Inter", ui-sans-serif, system-ui, sans-serif;
  --default-font-family: "Inter", ui-sans-serif, system-ui, sans-serif;
}

/* Data/Numbers — Tabular figures */
.tabular-nums {
  font-variant-numeric: tabular-nums;
}
```

This removes the Bebas Neue h1/h2/h3 rule (Pitfall 4 from research — it overrides Tailwind's global font) and removes the generic body/p/span/div rule (redundant once `--default-font-family` is set).

The `@theme` block tells Tailwind v4 to generate `html, :host { font-family: "Inter", ... }` automatically. The `--font-sans` override ensures `font-sans` utility also resolves to Inter.
  </action>

  </verify>
