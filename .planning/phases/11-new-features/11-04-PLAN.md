**Migration (supabase/migrations/20260217_phase11_comments.sql):**
Use the exact schema from research, with these elements in order:
1. CREATE TABLE community_comments (id UUID PK, item_id UUID NOT NULL, item_type TEXT CHECK IN ('routine','cycle'), user_id UUID REFERENCES auth.users(id), body TEXT CHECK char_length <= 500, created_at, updated_at, deleted_at nullable)
2. `ALTER TABLE community_comments ENABLE ROW LEVEL SECURITY;` — IMMEDIATELY after CREATE TABLE
3. SELECT policy: authenticated users view non-deleted comments (`deleted_at IS NULL`)
4. INSERT policy: PHOENIX/ELITE users only (`public.user_subscription_tier() IN ('PHOENIX', 'ELITE')`)
5. UPDATE policy: own comments within 5-minute window (`created_at > now() - INTERVAL '5 minutes'`)
6. DELETE policy: own comments only (`user_id = auth.uid()`)
7. Rate limit trigger function: check_comment_rate_limit() — counts recent comments, raises exception if >= 5 in last hour
8. Trigger: enforce_comment_rate_limit BEFORE INSERT
9. Indexes: item_id (WHERE deleted_at IS NULL), user_id, rate_limit composite (user_id, created_at)
10. `ALTER PUBLICATION supabase_realtime ADD TABLE community_comments;` — enable Realtime

Additionally, add `comment_count INT NOT NULL DEFAULT 0` column to both `shared_routines` and `shared_cycles` tables:
```sql
ALTER TABLE shared_routines ADD COLUMN IF NOT EXISTS comment_count INT NOT NULL DEFAULT 0;
ALTER TABLE shared_cycles ADD COLUMN IF NOT EXISTS comment_count INT NOT NULL DEFAULT 0;
```

Add trigger to auto-increment/decrement comment_count on INSERT/soft-DELETE:
```sql
CREATE OR REPLACE FUNCTION public.update_comment_count()
RETURNS TRIGGER LANGUAGE plpgsql SECURITY DEFINER AS $$
BEGIN
  IF TG_OP = 'INSERT' THEN
    IF NEW.item_type = 'routine' THEN
      UPDATE shared_routines SET comment_count = comment_count + 1 WHERE id = NEW.item_id;
    ELSE
      UPDATE shared_cycles SET comment_count = comment_count + 1 WHERE id = NEW.item_id;
    END IF;
    RETURN NEW;
  ELSIF TG_OP = 'UPDATE' AND NEW.deleted_at IS NOT NULL AND OLD.deleted_at IS NULL THEN
    IF NEW.item_type = 'routine' THEN
      UPDATE shared_routines SET comment_count = GREATEST(0, comment_count - 1) WHERE id = NEW.item_id;
    ELSE
      UPDATE shared_cycles SET comment_count = GREATEST(0, comment_count - 1) WHERE id = NEW.item_id;
    END IF;
    RETURN NEW;
  END IF;
  RETURN COALESCE(NEW, OLD);
END; $$;

CREATE TRIGGER update_comment_count_on_change
  AFTER INSERT OR UPDATE ON community_comments
  FOR EACH ROW EXECUTE FUNCTION public.update_comment_count();
```
