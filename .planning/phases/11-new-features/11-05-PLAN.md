**Comparison library (src/lib/comparison.ts):**
Pure function following the research code example:
```typescript
export interface SessionSummary {
  id: string;
  name: string;
  startedAt: Date;
  totalVolume: number;
  duration: number;
  exerciseCount: number;
  setCount: number;
  prCount: number;
  exercises: { name: string; volume: number; maxWeight: number; sets: number; avgVelocity: number }[];
}

export interface ComparisonResult {
  volumeDelta: number;       // percentage change
  durationDelta: number;     // percentage change
  exerciseDeltas: {
    name: string;
    volumeA: number;
    volumeB: number;
    deltaPct: number;
    velocityA: number;
    velocityB: number;
    velocityDeltaPct: number;
    onlyInA: boolean;
    onlyInB: boolean;
  }[];
  sharedExerciseCount: number;
  warning: string | null;    // "These sessions share fewer than 2 exercises"
}

export function compareSessions(a: SessionSummary, b: SessionSummary): ComparisonResult
```

Implementation: Match exercises by name, compute `(B - A) / A * 100` for volume/weight and velocity. Flag exercises only in A or only in B. Warning if shared count < 2. Velocity delta uses same percentage formula: `(velocityB - velocityA) / velocityA * 100`.

**ComparisonView page (src/app/components/ComparisonView.tsx):**
Route: `/compare?a={sessionId}&b={sessionId}` — reads session IDs from URL search params.

Layout:
1. Tier gate: `useSubscription().isPremium` — FREE users see upgrade prompt
2. Load both sessions: `useQuery(sessionDetailOptions(sessionAId))` and `useQuery(sessionDetailOptions(sessionBId))` — uses Zod-transformed data (avoids weight doubling)
3. Transform session detail data into SessionSummary format. For `avgVelocity` per exercise: `sessionDetailOptions` returns exercises with sets, but sets don't include velocity. Fetch rep summaries for each session's sets via `rep_summaries` table (same pattern as `sessionAsymmetryOptions` in `src/queries/biomechanics.ts`). Compute average `mean_velocity_mps` per exercise across all reps. If no rep summaries exist for an exercise, set `avgVelocity: 0`. Add a `comparisonDetailOptions(sessionId)` query in `src/queries/workouts.ts` that extends `sessionDetailOptions` to also fetch rep summaries and compute per-exercise avg velocity.
4. Call `compareSessions(summaryA, summaryB)` to get deltas (including velocity deltas)
5. Validation: if `a === b`, show error "Cannot compare a session with itself" (COMP-06)

Desktop layout (side-by-side):
- Two-column grid: Session A (left) | Session B (right)
- Each column: session name, date, summary stats (volume, duration, exercises, sets)
- Between columns: delta indicators with color coding (green for increase, red for decrease)
- Below: per-exercise breakdown table:
  | Exercise | Session A Volume | Session B Volume | Volume Change | Session A Velocity | Session B Velocity | Velocity Change |
  - Color-coded change columns: green +%, red -%, gray "only in A"/"only in B"
  - Velocity columns show avg velocity in m/s (from rep_summaries `mean_velocity_mps`). If no velocity data available for an exercise, show "—" instead of 0.
