  <name>Task 1: @media print CSS and navigation print-hide markers</name>
  <files>src/styles/theme.css, src/app/routes/AppLayout.tsx</files>
  <action>
Add `@media print` block at the end of `src/styles/theme.css` (after the `@layer base` block):

```css
@media print {
  /* ---- Hide non-report UI ---- */
  nav,
  [data-print-hide],
  .print\\:hidden,
  button:not([data-print-show]),
  .toaster,
  .sonner-toast {
    display: none !important;
  }

  /* ---- Print-friendly base styles ---- */
  body {
    background: white !important;
    color: black !important;
    -webkit-print-color-adjust: exact;
    print-color-adjust: exact;
  }

  /* ---- Page setup ---- */
  @page {
    margin: 1.5cm;
    size: A4 portrait;
  }

  /* ---- Card reset for print ---- */
  .bg-gradient-to-br,
  .bg-gradient-to-b {
    background: white !important;
    border-color: #e5e7eb !important;
  }

  /* ---- Ensure SVG charts print with colors ---- */
  svg {
    print-color-adjust: exact;
    -webkit-print-color-adjust: exact;
  }

  /* ---- Fix ResponsiveContainer dimensions for print ---- */
  .recharts-responsive-container {
    width: 100% !important;
    height: 300px !important;
  }

  /* ---- Text colors for print readability ---- */
  .text-white,
  .text-foreground {
    color: black !important;
  }

  .text-muted-foreground,
  .text-muted {
    color: #4b5563 !important;
  }

  .text-primary {
    color: #FF6B35 !important;
  }

  /* ---- Print-only elements ---- */
  .print-only {
    display: block !important;
  }

  /* ---- Prevent page breaks inside cards ---- */
  .exercise-card {
    break-inside: avoid;
  }
}
```

}

2. **Add Print Report button** in the session header area (near the "Back to History" button and Share button), inside a SubscriptionGate:

```tsx
<SubscriptionGate
  requiredTier="PHOENIX"
  fallback={null}
>
  <Button
    variant="outline"
    size="sm"
    onClick={() => window.print()}
    className="border-secondary text-muted-foreground hover:border-primary hover:text-primary print:hidden"
    data-print-hide
  >
    <Printer className="w-4 h-4 mr-2" />
    Print Report
  </Button>
</SubscriptionGate>
```

Note: Using `fallback={null}` so FREE users see nothing (not an upgrade prompt) — the button simply doesn't appear.
