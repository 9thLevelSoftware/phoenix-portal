## Key Decisions

- Inter Variable with non-standard weights 450/625 for premium type contrast
- Dual-token pattern: CSS vars for Tailwind, hex constants for SVG (visx)
- Max 3 backdrop-blur layers per viewport (GPU budget)
- AnimatePresence requires useOutlet() not <Outlet> for React Router v7
- @number-flow/react for stat counting (~4KB gzip)
- Card hierarchy: card-hero > card-primary > card-secondary
- Gradient text reserved for hero h1 only (2 instances)
- EmberParticles needs manual prefers-reduced-motion (Canvas outside MotionConfig)
- RechartsTooltip separate from visx ChartTooltip (different rendering models)
